    Class Qualifier

    A qualifier is a type-value-pair that makes additional statements w.r.t. the value of the element.

    Constraint AASd-006: If both the Qualifier.value and the Qualifier.valueId of a Qualifier are present then the Qualifier.value needs to be identical to the value of the referenced coded value in Qualifier.valueId.

    Constraint AASd-020: The value of Qualifier.value shall be consistent to the data type as defined in Qualifier.valueType.
