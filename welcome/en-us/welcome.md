# Welcome to AASPortal

AASPortal is a comprehensive web portal for visualizing and managing Asset Administration Shells (AAS). Our platform provides an intuitive interface to interact with Industry 4.0 assets and their digital representations.

<img src="../assets/aas-portal.svg" alt="AASPortal Logo" width=128>

## Start Page

The Start page is your gateway to AASPortal. Here you can:
- Access your favorite Asset Administration Shells
- Quickly navigate to frequently used views

## Shells

The Shells section is where you manage your Asset Administration Shell connections:
- Browse all available AAS endpoints
- Connect to different AAS sources including:
  - AASX Servers
  - OPC UA Servers
  - AAS Registries
  - Local AASX files
- Filter and search for specific shells
- View shell details and metadata

## AAS (Asset Administration Shells)

In the AAS section, you can work with individual Asset Administration Shells:
- Explore the complete AAS environment
- View asset information and properties
- Access submodels and their elements
- Navigate through concept descriptions
- Interact with shell components

## Views

The Views section provides specialized visualizations for different types of AAS data:
- Browser view for hierarchical navigation
- Documentation view for technical documents
- Contact information view
- Customized views for specific submodel types
- Support for various data formats and representations

## Dashboard

The Dashboard gives you an overview of your AAS ecosystem:
- Monitor connected endpoints
